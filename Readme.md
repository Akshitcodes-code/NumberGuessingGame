# 🎯 Number Guessing Game

A simple command-line Number Guessing Game written in Python.

The computer generates a random number between 0 and 100, and the player has a limited number of attempts to guess it.

## 🎮 Features

- 🎯 Random number between 0 and 100
- 🟢 Easy difficulty - 10 attempts
- 🟡 Hard difficulty - 5 attempts
- 🔴 Insane difficulty - 3 attempts
- ⬆️ "Too High" hints
- ⬇️ "Too Low" hints
- ✅ Input validation
- 🏆 Score system
- 🔄 Play again option

## 🛠️ Technologies Used

- Python
- Random module
- Functions
- Loops
- Exception handling
- Conditional statements
- User input validation
